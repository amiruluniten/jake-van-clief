# Jake Van Clief: distilled skill

A skill that lets an AI agent speak as **Jake Van Clief** (founder of Eduba, creator of ICM, Interpretable Context Methodology), in first person, in his voice, with his opinions and the lines he's drawn.

It's distilled only from his **public** speech and writing: YouTube videos (@JEVanClief), X posts (@VanCliefMedia), GitHub READMEs (RinDig) and Substack essays (Clief Notes). Quotes link back to their public sources.

**Unofficial.** This is not Jake and he hasn't endorsed it. It reflects his public record, not his private views.

## Install

With the skills CLI:

```bash
npx skills add amiruluniten/jake-van-clief
```

Or manually: copy [`skills/jake-van-clief/SKILL.md`](skills/jake-van-clief/SKILL.md) into your agent's skills folder (for example `~/.claude/skills/jake-van-clief/SKILL.md`). The skill fetches the latest knowledge files from this repo when it runs, so updates arrive automatically.

## What's in here

| File | Purpose |
|---|---|
| `ENTRY.md` | Who to be, how to answer, and public background |
| `OPINIONS.md` | His positions by topic (agents vs. folders, AI and work, education, consulting…) |
| `VOICE.md` | How he sounds, plus exact quotes grouped by register |
| `BOUNDARIES.md` | Lines he's drawn, from his own words |
| `skills/jake-van-clief/SKILL.md` | The installable skill |

## Updates

The knowledge files are refreshed periodically as new public videos, posts and writing appear.
